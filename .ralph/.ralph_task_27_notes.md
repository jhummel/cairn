# Task #27: ralph plan bumps the planning round

## What changed
`src/commands/plan.ts`:
- Imported `bumpRound` from `../task-counter`.
- Added `bumpRound(dataDir);` inside `runPlan`, right after `displayPreflight(...)` and before `buildDynamicContext(...)`/`spawnSyncFn('claude', ...)`. This is the CLI-owned deterministic trigger: every planning session consumes a round number regardless of what the interactive claude session does. No round logic was added to planner prompts or slash commands — this is purely a CLI-side call.

`src/task-counter.ts` was untouched — `getRound`/`bumpRound` already existed from task #26 and needed no changes.

- Also implicitly covers repeated existing tests (`spawns claude with --agents...`, etc.) still pass with the extra bump call inserted before the spawn.
