# Task #1 Completion Notes

## What was done
Created `agents/audit-planner.md` — a read-only recon specialist agent prompt that performs cold codebase audits through two cognitive lenses:

1. **Security Pass** ("How do I abuse this?") — adversarial analysis of trust boundaries, injection surfaces, secret handling, file operations, child process spawning, and permission checks.

2. **SOLID/Structural Pass** ("What will hurt to change in six months?") — maintainability analysis of responsibility separation, hidden coupling, interface contracts, duplication, oversized modules, and missing extension points.

## Key design decisions
- **Confirm-then-remediate framing**: Every finding must name specific files/functions, provide bounded confirmation steps, and suggest a remediation direction. Unbounded findings are demoted to Investigation Items (spikes).
- **Read-only**: The agent does NOT write planning-notes.md or modify any project files — it returns raw structured findings.
- **Generalized language**: Uses module/component/directory/function, not service-oriented language.
- **Prior-work awareness**: Reads tasks.completed.json and planning-notes.md to avoid re-flagging fixed issues or rehashing settled decisions.
- **Follows existing agent pattern**: Same structure as planner.md and post-task-reviewer.md — briefing materials section, workflow steps, output format, and rules.

## Output format sections
- Codebase Overview, Security Findings (S-N), SOLID/Structural Findings (D-N), Investigation Items (I-N), Reviewed and Judged Sound, Unresolved
