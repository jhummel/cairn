# Task #2 Completion Notes

## What was done

Created `commands/codebase-audit.md` — the slash command that wraps the `audit-planner` agent.

### Slash command design

The command follows the pattern from `commands/generate-tasks.md`:
1. Spawns the `audit-planner` agent via the Agent tool (reads `agents/audit-planner.md` and passes its contents as the prompt)
2. Receives the structured findings report
3. Presents a concise summary organized by severity (security) and impact (structural) — not the raw output
4. Invites the user to discuss findings, dismiss false positives, add context
5. When discussion is complete, writes `.ralph/planning-notes.md` in the standard format (Context, Goals, Approach, Rejected Alternatives, Rough Task Outline, Open Questions)
6. Suggests running `/generate-tasks` next

### Key design decisions

- The command instructs the planner to read `agents/audit-planner.md` and pass it verbatim rather than embedding the full audit prompt inline. This keeps the slash command maintainable and ensures changes to the audit-planner agent are automatically picked up.
- Discussion mode is explicit: the command tells the agent not to rush to writing planning notes, staying in conversation until the user signals readiness.
- The summary format groups security findings by severity and structural findings by impact, with clean areas called out so the user knows what doesn't need attention.
