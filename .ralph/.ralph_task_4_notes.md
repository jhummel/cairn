# Task #4 Completion Notes

## Finding: `--allowedTools` DOES restrict the `Agent` tool

### How `--allowedTools` works

The Claude CLI has two distinct flags:
- `--tools <tools...>` — controls which built-in tools are **available at all**
- `--allowedTools <tools...>` — controls which tools are **auto-approved** (no permission prompt)

In **interactive mode** (no `-p`), `--allowedTools` means:
- Listed tools: auto-approved, no user prompt required
- Unlisted tools: user sees a permission prompt before each use

In **non-interactive mode** (`-p`), `--allowedTools` acts as a true whitelist: unlisted tools are **blocked entirely**.

The planner is spawned in interactive mode (`stdio: 'inherit'`, no `-p`), so with the old allowlist `Read,Glob,Grep,Write,Edit`, the `Agent` tool was NOT blocked — but it would have prompted the user for permission every time a slash command like `/generate-tasks` or `/codebase-audit` invoked it.

### What was changed

`src/commands/plan.ts` line 162:
```
Before: '--allowedTools', 'Read,Glob,Grep,Write,Edit'
After:  '--allowedTools', 'Read,Glob,Grep,Write,Edit,Agent'
```

This ensures the `/generate-tasks` and `/codebase-audit` slash commands can use the `Agent` tool to spawn subagents without interrupting the user with a permission prompt.
